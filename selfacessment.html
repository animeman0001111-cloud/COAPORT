2. Design and implement 4×4 memory using single cell memory

Introduction

A memory cell is the fundamental unit of RAM. A single SRAM cell stores one bit. Arranging cells in rows (word lines) and columns (bit lines) builds a complete memory array. This design uses SRAM cells to create a 4×4 memory — 4 locations each storing 4 bits.

Working of a Single SRAM Cell

Components:

  • Two cross-coupled CMOS inverters (INV1 and INV2), forming a bistable latch
  • Two NMOS access transistors (N1 and N2), controlled by the Word Line (WL)

Ports:

  • WL (Word Line): Activates the cell for read/write
  • BL (Bit Line): Carries data during write; read ones during read
  • BL̄ (Complement Bit Line): Carries the inverted data bit

4×4 Array Operation:

The 4×4 array has 4 rows and 4 columns. A 2-to-4 row decoder selects one WL at a time. All 4 bit lines carry one bit each, forming a 4-bit data word.

Conclusion:

The 4×4 SRAM uses 16 single-bit cells in a matrix. The row decoder selects the word line; bit-line sense amplifiers complete read/write operations. This technique is fundamental in practical memory design.

3. Design and implement a 1024×32 memory using 512×16 memory chips.

Introduction

A 512×16 chip has 512 addressable locations storing 16 bits each. To build 1024×32, we must expand both depth (512→1024) and width (16→32 bits).

Design Steps

Step 1 — Expansion needed:

  • Width: 32 ÷ 16 = 2 chips in parallel per bank
  • Depth: 1024 ÷ 512 = 2 banks
  • Total chips: 2 × 2 = 4 chips

Step 2 — Address partitioning:

  • Total address bits = log₂(1024) = 10 bits: A[9:0]
  • A[8:0] (9 bits) → all chips as row address
  • A[9] (MSB) → 1-to-2 decoder → CS0 or CS1

Step 3 — Data bus:

  • Chip A & C → D[15:0] (lower 16 bits)
  • Chip B & D → D[31:16] (upper 16 bits)

Conclusion:

Four 512×16 chips build a 1024×32 memory using width-expansion (parallel chips) and depth-expansion (chip-select decoding). This technique is widely used in practical memory subsystem design.

4. Design and implement both alternatives of a dual-ported 8-bit register file having 8 registers.

Introduction

A register file is fast internal memory inside a processor. A dual-ported register file supports two simultaneous reads and one write — essential for ALU instructions needing two source operands simultaneously.

Design Specification

  • Number of registers: 8 (R0–R7)
  • Width of each register: 8 bits
  • Ports: 2 read ports (RA, RB) + 1 write port (RW)
  • Address width: log₂(8) = 3 bits per port

5. Design hardware for: (i) Add R0, R1, R2   (ii) Add R0, R1, #0x45

Introduction

The datapath connects the register file, ALU, and memory to execute instructions. We need hardware for two cases: register-to-register addition, and register-to-immediate addition.

Required Hardware

  • Register File — 8 registers (R0–R7), 8-bit each, 2 read + 1 write port
  • ALU — Performs addition
  • Multiplexer (MUX) — Selects between register data and immediate value
  • Code Memory — Stores instructions
  • Control Unit — Generates control signals

Instruction Tracing

1. Add R0, R1, R2

  1. Fetch instruction from code memory
  2. Register file reads R1 → Data A, R2 → Data B
  3. MUX selects Data B (register value)
  4. ALU: Result = R1 + R2
  5. Result written back to R0

2. Add R0, R1, #0x45

  1. Fetch instruction from code memory
  2. Register file reads R1 → Data A
  3. Immediate value 0x45 extracted
  4. MUX selects Immediate
  5. ALU: Result = R1 + 0x45
  6. Result written back to R0
