Chapter 2

Performance Metrics: CPI, IPC, MIPS, FLOPS & Benchmarking

This chapter covers the fundamental quantitative measures used to evaluate and compare processor performance — Amdahl's Law, CPI, MIPS, Execution Time, and benchmarking methodologies through solved numerical examples.

1. Dual Pentium — Amdahl's Law (Parallelism)

Problem Statement

Two applications run on a dual Pentium processor. Application 1 needs 80% of resources (40% parallelizable). Application 2 needs 20% (99% parallelizable).

Amdahl's Law: Speedup = 1 / [(1 − P) + (P / N)]
i) Application 1 — 40% Parallelizable, N = 2
P = 0.4, N = 2
Speedup = 1 / [(1 − 0.4) + (0.4 / 2)] = 1 / (0.6 + 0.2) = 1 / 0.8
✓ Speedup = 1.25
ii) Application 2 — 99% Parallelizable, N = 2
P = 0.99, N = 2
Speedup = 1 / [(1 − 0.99) + (0.99 / 2)] = 1 / (0.01 + 0.495) = 1 / 0.505
✓ Speedup ≈ 1.98

3. Enhancement of Overall Speedup

Problem Statement

An enhancement runs 10× faster but is usable only 40% of the time.

Speedup = 1 / [(1 − F) + (F / N)]
i) 10% of Program 10× Faster
F = 0.10, N = 10
= 1 / [(1 − 0.10) + (0.10 / 10)] = 1 / (0.90 + 0.01) = 1 / 0.91
✓ Overall Speedup ≈ 1.099
ii) 90% of Program 10× Faster
F = 0.90, N = 10
= 1 / [(1 − 0.90) + (0.90 / 10)] = 1 / (0.10 + 0.09) = 1 / 0.19
✓ Overall Speedup ≈ 5.263

Observation: Increasing the fraction of the program that benefits from the enhancement significantly increases the overall speedup.

7. CISC vs RISC — VAX 11/780 vs IBM RS/6000

Given Data
ProcessorClock FrequencyPerformanceCPU Time
VAX 11/7805 MHz1 MIPS12x seconds
IBM RS/600025 MHz18 MIPSx seconds

VAX requires 12× longer CPU time than IBM.

b) CPI Values
CPI = Clock Rate (MHz) / MIPS
CPI(VAX) = 5 / 1 = 5.00
CPI(IBM) = 25 / 18 = 1.389
✓ CPI(VAX) = 5.00 | CPI(IBM) = 1.389
a) Relative Instruction Count
IC(VAX)/IC(IBM) = (CPI_IBM/CPI_VAX) × (Clock_VAX/Clock_IBM) × 12
= (1.389/5) × (5/25) × 12 = 0.2778 × 0.2 × 12 = 0.6667
✓ IC(VAX) / IC(IBM) ≈ 2/3 = 0.667

The VAX executes approximately two-thirds as many instructions as the IBM for this benchmark, but each VAX instruction takes far more cycles (CPI = 5 vs 1.389), making it 12× slower overall.

10. 8-Core Parallel Execution — Speedup Factor

Modified CPI with Cache Contention (cache miss CPI = 12)

Average CPI = 0.60 + 0.36 + 0.48 + 1.20 = 2.64

Speedup = MIPS(parallel) / MIPS(single) = 151.52 / 178.57
✓ Average CPI = 2.64 | MIPS = 151.52 | Speedup = 0.85

Conclusion: The increased cache miss penalty (CPI 8 → 12) due to memory contention raises average CPI from 2.24 to 2.64, reducing MIPS from 178.57 to 151.52. The speedup factor of 0.85 means the 8-core version is actually slightly slower than the single-core version for this workload — memory contention erases the parallelism benefit.
