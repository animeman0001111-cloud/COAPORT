Overview of Modern Processors:
Samsung Exynos 2400
Computer Organisation & Architecture — Processor Deep-Dive Study
1. Introduction

The Samsung Exynos 2400 is a high-performance flagship mobile processor (System-on-Chip) developed by Samsung Semiconductor for the Galaxy S24 series smartphones in select regions. It is fabricated on Samsung's 4nm LPP+ process node and integrates a 10-core CPU cluster, a GPU, a dedicated NPU, an ISP, a DSP, and a 5G modem onto a single die.

The Exynos 2400 represents Samsung's most ambitious SoC to date, featuring heterogeneous multi-core design based on ARM's big.LITTLE architecture (ARMv9-A ISA), an AMD RDNA 3-based Xclipse 940 GPU capable of ray tracing, and an NPU delivering 34.7 TOPS of AI performance.

2. ALU and Control Unit

The Exynos 2400 implements multiple CPU cores based on ARM architecture (ARMv9 cores). Each core includes an Arithmetic Logic Unit (ALU) that performs operations like addition, subtraction, comparisons, and logical functions. The prime Cortex-X4 core features multiple ALUs and a dedicated Multiply-Accumulate (MAC) unit operating in parallel inside an out-of-order superscalar pipeline.

The Control Unit (CU) manages instruction fetch, decode, dispatch, and retirement. In the Cortex-X4 prime core, this is handled via a wide 8-wide instruction decode pipeline with advanced branch prediction, speculative execution, and out-of-order execution — maximising throughput and minimising data hazards.

3. Memory Organisation

The Exynos 2400 uses a hierarchical memory system rooted in Modified Harvard Architecture:

  • L1-I Cache (per core — instructions only): 32–64 KB depending on core type
  • L1-D Cache (per core — data only): 32–48 KB depending on core type
  • L2 Cache (unified, shared within clusters): 1 MB (prime) / 4 MB (perf+eff)
  • L3 Last-Level Cache (LLC) (shared across all CPU cores + GPU): ~12 MB
  • LPDDR5X Main RAM: up to 12 GB at 68 GB/s bandwidth

The separation of L1-I and L1-D caches allows simultaneous instruction fetch and data access, eliminating the Von Neumann bottleneck at the most performance-critical level. This structure improves throughput and reduces memory latency significantly.

4. System Bus and Interconnections

Communication inside the Exynos 2400 is achieved through a mesh-based high-speed internal interconnect (CMN-700 / CoreLink CCI-600). Samsung uses an advanced interconnect fabric to connect the CPU cluster, GPU (Xclipse 940), NPU, ISP, DSP, and modem to LPDDR5X DRAM. This supports fast data transfer between components and enables true parallel processing.

  • Instruction bus — fetches instructions from L1-I cache → decode pipeline
  • Data bus — moves operands via L1-D cache ↔ execution units
  • Cache coherence bus — MESI protocol across all cores via CMN-700 mesh
  • AXI/ACE system fabric — connects CPU, GPU, NPU, ISP → DRAM controller
5. Type of Architecture

The Exynos 2400 follows a Modified Harvard Architecture:

  • Separate instruction and data caches at L1 level (Harvard feature)
  • Unified shared memory at L2/L3 and DRAM (Von Neumann at system level)

Salient features:

  • Heterogeneous 10-core CPU (1+2+3+4 big.LITTLE cluster design)
  • ARMv9-A ISA with SVE2, MTE, and TrustZone security
  • Out-of-order superscalar execution; 8-wide decode in prime core
  • Integrated Xclipse 940 GPU (AMD RDNA 3) with hardware ray tracing
  • Tri-core NPU — 34.7 TOPS for on-device AI
  • Integrated 5G sub-6 GHz + mmWave modem on the same die
Key Insight: The Modified Harvard Architecture allows the Cortex-X4 to simultaneously fetch the next instruction AND read/write data operands — something impossible on a classic single-bus Von Neumann design. This is critical for sustaining the 8-wide decode pipeline at 3.21 GHz.

8. Other Important Information
  • Built on 4nm technology, making it highly power-efficient compared to previous generation 5nm chips.
  • Uses ARMv9-A architecture for better security, performance, and expanded AI capabilities.
  • Supports advanced camera processing via the multi-core ISP capable of 200MP stills and 8K video recording.
  • The integrated Xclipse 940 GPU (AMD RDNA 3) brings PC-class graphics features like ray tracing and hardware-accelerated mesh shading to mobile.
  • Includes 34.7 TOPS AI capabilities for tasks like on-device translation, photo enhancement, generative AI, and computational photography.
  • The Modified Harvard Architecture ensures the CPU never suffers the Von Neumann bottleneck at the L1 cache level — critical for sustaining 10-core parallel execution at peak performance.
